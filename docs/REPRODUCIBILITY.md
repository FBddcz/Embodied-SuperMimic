## 算法代码包的目标结构

下面是下一阶段的设计，不代表当前仓库已有这些文件：

```text
src/embodied_supermimic/   # 机器人、任务、训练、评测
configs/robots/           # 机器人绑定和控制设置
configs/tasks/            # 各任务物理和成功标准
configs/experiments/      # 精确复现实验参数
scripts/                  # 单一train/evaluate/record入口
assets/                   # 许可清晰的资源或下载manifest
results/                  # 汇总，不放巨大checkpoint
artifacts/                # 运行时输出，git忽略
```

环境路径不写死。数据、缓存、输出通过CLI参数或显式配置指定；提供Linux/CUDA版本锁和低资源smoke；运行脚本根据仓库根目录解析路径。

## 发布前必须完成

1. 上游来源、模型资产和任务道具许可逐项确认，保留修改记录；本次生成的研究演示不授权分发 ShapeNet 或其他原始模型。
2. 25格至少分别记录适配/开发库/全量bank/训练/评测状态，不用一个勾代替全部。
3. 每次训练记录依赖、commit、seed、模型配置、控制周期和预算。
4. bank/checkpoint 发布 SHA256、协议 ID、split、场景/配置哈希与 task/robot 契约；本次不分发这些文件。网页 manifest 同时覆盖公开元数据，已有原始评测哈希只是归档来源标识，不能声称已在本包重新计算。
5. 从干净环境执行最小数据集smoke、checkpoint重载和独立评测。
6. 文档给出完整失败排查：GPU容量、观察维度、夹爪坐标、复位提案失败、日志位置。
7. 清除过时脚本、用户路径、凭据和未检查的实验分支。

我们宁可写清“尚不可训练复现”，也不把只有网页能打开包装成完整即插即用训练包。
